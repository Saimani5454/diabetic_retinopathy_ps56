# diabetic_retinopathy_ps56
🩺 Diabetic Retinopathy Predictor

👉 Live Demo: https://diabeticretinopathyps56-1.streamlit.app/

📌 Project Overview

This web application predicts the risk of Diabetic Retinopathy (DR) using basic patient health data. By entering age, blood pressure, and cholesterol levels, users receive a personalized risk score along with clinically relevant recommendations for next steps.

🚀 Features

🔮 Personalized Risk Prediction – Instant probability-based assessment (Low, Moderate, High).

🧠 Multiple ML Models – Choose from Logistic Regression, Random Forest, XGBoost, LightGBM, and more.

📊 Model Evaluation Dashboard – Interactive charts and metrics comparison for transparency.

🛡 Safe & Robust – Graceful handling of missing models/artifacts with clear guidance.

💡 Actionable Recommendations – From routine screenings to urgent referrals depending on risk level.

⚡ Why It Matters

Diabetic Retinopathy is a leading cause of blindness worldwide. Early prediction and timely action can prevent vision loss. This app bridges machine learning insights with real-world clinical guidance—empowering both patients and healthcare professionals.

🛠 Tech Stack

Frontend & Deployment: Streamlit

Machine Learning: Scikit-learn, XGBoost, LightGBM

Visualization: Plotly, Matplotlib

Data Handling: Pandas, NumPy
